ELRINCÓN VERDE.

Este proyecto es una resolución bella y minimalista a un e-commerce, en este caso de
venta de plantas. Con accesos rápidos de encontrar y simples de manejar, para que 
cualquier persona pueda comprar desde la comodidad de su casa.
